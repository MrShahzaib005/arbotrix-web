## 📋 Overview

The **Arbotrix Web Platform** is the digital command center for a high-end physical robotics and autonomous mechanics academy. It is designed to bridge the gap between software logic and hardware execution.

Moving away from generic SaaS templates, this platform utilizes a custom **"Hybrid Executive" aesthetic**—blending deep, cinematic dark themes for primary hero sections with stark, blueprint-grid white components for technical data, resulting in a highly readable and premium user experience.

### ✨ Key Features
- **Dynamic Course Catalog:** Real-time fetching of engineering modules (ROS2, Edge AI, Python) directly from the database.
- **Asymmetric UI/UX Design:** High-contrast layout utilizing Framer Motion for fluid, hardware-accelerated animations.
- **Frictionless Enrollment Pipeline:** Direct integration with Google Forms for rapid student lead capture, bypassing heavy authentication walls.
- **Responsive "Command Center" Styling:** Engineered with Tailwind CSS, utilizing custom blurs, gradients, and custom SVGs over third-party icon bloat.

---

## 🛠️ Technical Architecture

This application is built on a modern, edge-ready tech stack optimized for speed and developer experience:

- **Frontend:** Next.js 14 (App Router), React, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Next.js Server Actions
- **Database ORM:** Prisma
- **Database Host:** Supabase (PostgreSQL)
- **Icons:** Raw Native SVGs (for zero-dependency reliability)
